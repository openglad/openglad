Openglad

Heads up, Firefox players — Firefox reserves Ctrl+W (close tab), and a web page cannot intercept it, even in fullscreen. Openglad's browser defaults therefore use Z to attack and X for your special, so you never hold Ctrl while moving. If you rebind attack to Ctrl in Options → Controls, walking up will close this tab.
