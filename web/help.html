Ctrl+W Closes the Tab

Browsers own Ctrl + W (close tab) in windowed play — Firefox closes the tab even when the page handles the key, and Chrome never delivers it to the page at all; only newer browsers allow capturing it, and only inside fullscreen. That is why Openglad's browser defaults bind player 1's attack to Z and special to X instead of the desktop Ctrl/Alt defaults. Only Ctrl is beyond reach: Alt stays bound to special because the game page suppresses Firefox's Alt menu-bar shortcut while still passing the key to the game.

If player 1 switches to 8-direction movement, Z and X become diagonal movement keys, so attack moves to S in the middle of the movement keys, special stays on Alt, and yell moves to V. Look-up starts unbound there — assign it in Options → Controls if you want it.

Warning: If you rebind attack to Ctrl in Options → Controls, attacking while walking up (Ctrl + W) will close the game tab. On Linux, Ctrl + Q can quit Firefox entirely. Your progress is saved automatically, but the game will still vanish mid-fight — keep attack off Ctrl in the browser.

macOS: Arrow Keys Not Working?

If pressing arrow keys triggers macOS system actions (like Mission Control or switching between Spaces) instead of controlling the game, you'll need to disable some system keyboard shortcuts.

1. Disable Mission Control Shortcuts

System Settings → Keyboard → Keyboard Shortcuts → Mission Control

Uncheck (disable) all arrow-based shortcuts:

  • Control + ← Move left a space
  • Control + → Move right a space
  • Control + ↑ Mission Control
  • Control + ↓ Application windows
  • Any "Switch to Desktop N" entries

2. Disable Accessibility Keyboard Navigation

System Settings → Accessibility → Keyboard

Set the following option:

  • Full Keyboard Access = OFF

This prevents arrow keys from being used for system-wide UI navigation.

3. Check for Custom App Shortcuts

System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts

Look for and remove any custom shortcuts that use:

  • ⌃ Control + Arrow keys
  • ⌥ Option + Arrow keys
  • ⌘ Command + Arrow keys
Note: These are system-wide settings. After changing them, your arrow keys will no longer trigger Mission Control or Spaces switching in any application. You can re-enable them after playing if needed.
