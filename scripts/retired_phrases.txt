# prose as a current statement.
#
# A row is `regex<TAB>sample<TAB>reason`:
#   regex   an ERE, case-sensitive, matched by scripts/check_retired_phrases.sh
#           against every prose line AND against every line joined with the
#           next one (a phrase re-wrapped at column 74 is still a phrase).
#   sample  one line of text the regex must flag.  The self-test plants it in
#           a temp tree and fails if the gate does not report it, so a regex
#           that rots -- or that this repo's awk cannot compile -- reds
#           scripts/test_check_retired_phrases.sh instead of going quietly
#           toothless on the real tree.
#   reason  printed beside every hit.  Say what is TRUE now and where the
#           record is, not just that the old text is wrong.
#
# Adding a row is the job of the PR that retires the phrase; a row is never
# removed while the phrase is still wrong, only when the fact it names comes
# back (then the statements were right all along).
#
# Two constraints on the regex column:
#   - No interval expressions ({2}, {1,3}).  CI's awk is mawk.
#   - No `\`` escape.  GNU grep reads it as the start-of-buffer anchor, so an
#     escaped backtick can never match; write the backtick plainly.
#
# The retired wave-row LABEL is deliberately not a row here (and is not spelled
# in this file, which the label gate also reads): scripts/check_retired_hud_labels.sh
# is its one implementation -- it scans src/, tests/ and cmake/ too, and carries
# the count allowlist those historical mentions need.  Two gates for one rule
# would be a rule twin.
#
