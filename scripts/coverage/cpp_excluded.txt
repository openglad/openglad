# Tracked src/**/*.cpp translation units the coverage build cannot measure.
#
# The C++ coverage denominator is whatever the ci-coverage build emitted
# .gcno for. A TU compiled only in some OTHER configuration — or one gcov has
# nothing to say about — is simply absent from the gcov data, and absent
# looks exactly like nothing: a build regression that silently stopped
# compiling a tested file would read as a slightly smaller denominator, not
# as a failure. scripts/coverage/coverage_report.py therefore requires every
# git-tracked src/**/*.cpp to either appear in the measured data or be listed
# here with a reason. Rot is an error in both directions: a listed TU the
# data DOES measure, or one git no longer tracks, fails the run until the
# line is deleted.
#
# Format: <repo-relative path> <reason>   (one per line, reason mandatory)

src/core/frame_rate_config.cpp no-coverable-lines: the TU is a single static_assert; its .gcno carries no line records, so gcovr emits no record for it
src/fuzz/fuzz_savefile.cpp fuzz-only TU: libFuzzer driver, built by the ci-fuzz preset, never part of the test suite
src/fuzz/fuzz_scenario.cpp fuzz-only TU: libFuzzer driver, built by the ci-fuzz preset, never part of the test suite
src/platform/emscripten/web_runtime_diagnostics.cpp emscripten-only TU: compiled only for the wasm target, which has no gcov
src/platform/emscripten/web_touch_bridge.cpp emscripten-only TU: compiled only for the wasm target, which has no gcov
