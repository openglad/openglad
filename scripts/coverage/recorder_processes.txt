# The recorder processes a full collection run must produce dumps from.
#
# scripts/coverage/coverage_report.py requires the SET of P records across
# the run's *.luacov dumps to equal this list. Losing a process is invisible
# in a percentage — it reads as slightly lower coverage, and with slack above
# the bar as nothing at all (dropping 51 of 61 dumps was an audit's cheapest
# attack) — so the population is checked structurally, not numerically.
# Set equality, deliberately: a rerun of a flaky binary adds dumps, never
# names, while a binary that stops reporting (or a new one nobody listed)
# fails the run in a diff a reviewer reads.
#
# The rule that keeps that promise buildable: a ctest entry that is the sole
# producer of a name listed here may not be lane-gated. Gate it and every lane
# without the gate fails the population check instead of reporting coverage.
#
# Regenerate after adding or removing a test binary:
#   grep -h '^P' build/ci-coverage/coverage/lua-raw/*.luacov | cut -f2 | sort -u
